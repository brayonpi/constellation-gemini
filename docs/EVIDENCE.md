# Evidence and claim language

Constellation keeps four distinct statements separate:

- Gemini compiled a declared operator input into a schema-valid canonical model.
- HexStellar returned a candidate and the exact certainty reported by its public API.
- The independent verifier established a declared set of simulation-domain properties.
- The sandbox accepted a verified patch.

One statement never implies the others.

Local MacBook timings are development observations only and are not published as performance results.
Matching a reference objective validates a recomputation; it does not certify global optimality.
The application reports `met: false`, the uncovered obligations, and a concrete recovery option whenever the hard mission contract is infeasible.

The five-paraphrase test supports only this statement:

> These five committed paraphrases compiled to the same canonical mission model.

It does not establish general language understanding or paraphrase invariance.

Operational latency displayed in the interface describes only that observed request.
It is not a benchmark, acceleration claim, or comparison with another system.

> **BRAYON PIESKE** | *"Engineering earns trust when every claim is testable and every release is verified."*
