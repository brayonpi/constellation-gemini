# Submission checklist

Official deadline: **2026-08-31 at 17:00 PDT (America/Los_Angeles)**.
Source: [All Things Agentic official rules](https://allthingsagentichackathon.devpost.com/rules).

- [ ] Taskmaster selected as the single core category.
- [ ] HexStellar organizational consent and Startup Excellence eligibility confirmed.
- [ ] All team members and corporate email added to Devpost.
- [ ] Public repository and hosted application remain available through judging after explicit owner approval.
- [ ] If publication is delayed, grant private repository access to `testing@devpost.com` and `cloudhackathons@google.com` as the rules require.
- [ ] Real Gemini 3.5 Flash call and Google ADK execution visible in logs/video.
- [ ] Pub/Sub event initiates the workflow without a UI launch action.
- [ ] Cloud Run, Pub/Sub, Firestore, and Vertex AI operation visibly demonstrated.
- [ ] Borg extraction manifest contains timestamps, counts, hashes, and attribution.
- [ ] Four-minute public English video matches the submitted build.
- [ ] Architecture diagram, local instructions, cloud instructions, and verifier command work.
- [ ] Non-affiliation and pre-existing Cortex disclosures remain visible.
- [ ] No decorative third-party logos or implied endorsement.
- [ ] Exact submitted commit is tagged and frozen before the deadline.
- [ ] Post-deadline work happens only outside the submitted frozen artifact.
- [ ] [Release inventory](RELEASE_INVENTORY.md) and [release audit](RELEASE_AUDIT.md) match the frozen commit.

The repository remains private until every release blocker in [RELEASE_AUDIT.md](RELEASE_AUDIT.md) is closed and the owner explicitly authorizes publication.
